# Flutter-Atlas

Welcome to **Flutter-Atlas**! This repository serves as the central hub for my Flutter and Dart learning journey. It contains my daily UI practices, widget explorations, module-wise code, and mini-projects.

**👨‍💻 Developer:** Md Saiduzzaman (CSE, Southeast University)

---

## 📂 Repository Structure

To keep everything clean and professional, this repository is divided into the following sections:

*   📁 **`flutter_practice/`**: Contains core module-wise practices (UI elements, layout structures, and logic).
*   📁 **`Mini_Projects/`**: Standalone small applications (e.g., `portfolio_app`) built to apply the learned concepts.
*   📁 **`Assignments/`**: Various academic and course-related assignments.

## 💡 How to Run the Code

1. **Clone this repository:**
   ```bash
   git clone https://github.com/saiduzzaman-sojib/Flutter-Atlas.git
   ```
2. **Navigate to the specific directory (e.g., flutter_practice):**
   ```bash
   cd flutter_practice
   ```
3. **Fetch dependencies & Run:**
   ```bash
   flutter pub get
   flutter run
   ```
